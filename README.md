# Rental Platform

Rental and recurring bill management platform for Nepal.

## Tech Stack

### Frontend

- React
- Vite
- TypeScript
- Tailwind CSS
- React Router
- TanStack Query
- Axios

### Backend

- Node.js
- Express
- TypeScript
- Prisma
- PostgreSQL

### Authentication

- JWT access/refresh tokens
- Secure password hashing
- Role-based authorization
